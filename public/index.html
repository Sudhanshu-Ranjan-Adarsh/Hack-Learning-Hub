What is Hack? +

Hack is a demo learning hub: a place to explore a learning path, read or watch resources, take short quizzes, and keep basic progress while signed in.

Who is this for? +

Beginners and curious builders who want a clear path from learning fundamentals to building useful projects.

What does this demo store? +

The starter stores account details securely using password hashes and records quiz scores in Mariadb/MySQL. It does not include email verification, password reset, or admin content management yet.

THE LEARNING PATH

From fundamentals to full stack.

A simple roadmap for understanding how the web works, one layer at a time.

SUGGESTED ORDER

Learn → Practise → Connect → Ship

Move forward when you can explain the idea and demonstrate it.

01 → 02 → 03 → 04
01FOUNDATION

Frontend essentials

Build the interface people see and interact with.

  • HTML structure, semantic elements and forms
  • CSS layout, responsive design and accessibility
  • JavaScript events, arrays, objects and fetch()
Suggested: 1–2 weeksStudy materials ↗
02SERVER

Backend & APIs

Handle requests, validate input and return responses.

  • Node.js runtime and npm dependencies
  • Express routes, middleware and JSON
  • HTTP methods, status codes and error handling
Suggested: 1–2 weeksStudy materials ↗
03DATA

Database & identity

Store data safely and connect it to application logic.

  • SQL tables, keys, SELECT and INSERT
  • Mariadb/MySQL and parameterized queries
  • Password hashing, sessions and access checks
Suggested: 1–2 weeksStudy materials ↗
04DEPLOY

Integration & hosting

Ship the app so multiple users can access it online.

  • Environment variables and production settings
  • Git, deployment and hosted Mariadb/MySQL
  • Testing, logs, backups and security basics
Suggested: 1 weekStudy materials ↗
i
System standard

Keep secrets on the server, validate every request, use HTTPS in production, and never trust browser input just because the form validates it.
